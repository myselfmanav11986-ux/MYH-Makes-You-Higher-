# MYH Professional Website

GitHub Pages-ready professional website with a scalable local-business directory.

## Current
- Professional responsive MYH design
- Services, About and Contact sections
- Business directory
- Search and category filtering
- Each business can have name, category, location, rating, image, official website, Google/Maps link and phone
- Static and free to host

## Add a business
Edit `businesses.js`, add an object inside `BUSINESSES`, and upload its image to `assets/`.

## Future upgrades
This structure is deliberately separated so the frontend can later connect to a database/backend. Possible upgrades: owner submission form, admin dashboard, business login, image uploads, claim/verification, individual business pages, SEO/structured data, analytics, featured listings and payments.

A listing on MYH is not access to or ownership of a Google Business Profile. Publish only information you are authorized to publish.
